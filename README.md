# keyboard
A simple keyboard I'm making which may or may not work to learn schematics and PCB design. This was part of the keeb program at Hack Club (keeb.hackclub.com) This took me a while to make and was made using
- Kicad
- Fusion
- My Brain
All files required to make it should be here. I hope you find this useful!
